How to use this site

  • Use the navigation bar (top of page) or start from the homepage.
  • Country names in URLs use underscores, e.g. United_States. In the forms, you can type spaces (e.g. “United States”).
  • If you omit year, we use the latest available year.
  • If you omit entity (leave the Country field blank), you will see a top list. (This is how the Ranking page shows a list when no country is provided.)

Common routes

  • /deforestation – forest change lookup or top list
  • /co2 – CO₂ per capita lookup or top list
  • /ranking – country rank or top list (order = loss|gain)
