About this site

A database-driven Flask website for exploring two climate indicators by country and year.

Data source

Values are queried from our team PostgreSQL database on stearns using the records library. The dashboard combines two datasets: CO₂ emissions per capita and annual change in forest area.

Accessibility

Forms use matching label for and id, headings structure each page, and focus styles support keyboard navigation.

How to use

Start on the homepage, choose a country and year, then view the dashboard. The dashboard also includes a year-by-year table so you can scan trends quickly.
