About this site

This project provides both a user-facing website and a JSON API for exploring climate-related datasets (forest change and CO₂ emissions per capita).

How to use the website

  • Deforestation: look up annual change in forest area for a country and year.
  • CO₂: look up annual CO₂ emissions per capita for a country and year.
  • Ranking: see how a country ranks for forest change (loss or gain).

API access

JSON endpoints are available under the /api prefix. For example:

  • JSON: deforestation for United States (2021)
  • JSON: CO₂ per capita top 3 (2021)
